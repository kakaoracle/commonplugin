## ⛩ 此地为何处

传说每个网页的背后，都住着一群吵闹的小妖精：
它们把留言搬走、把广告堆成山、把正文挤到墙角罚站。

这里住着一位**扫除系魔女**。
她不写长篇大论的说明书，只在夜深人静时挥一挥扫帚 ——
第二天醒来，页面就变回了它本来该有的样子。

她随身还带一颗水晶球，专门收留迷路的乱码星尘。
